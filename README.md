# Odoo Jewelry

Система управления ювелирным производством на базе Odoo 19 Community Edition.

[Функциональная документация](openspec/docs/capabilities/README.md)

Структура проекта  
main/ — основные модули проекта;  
forks/ — изменённые сторонние модули;  
3party/ — сторонние зависимости;  
openspec/ — спецификации и проектная документация.
